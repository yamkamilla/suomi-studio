# Железо: живой трекер тренировок

Веб-приложение для телефона: отмечаешь подходы прямо в зале, видишь прошлые веса,
таймер отдыха идёт сам, рекорды ловятся автоматически, самочувствие и вес тела
пишутся в утренний чек-ин, а прогресс рисуется по неделям и по каждому упражнению.

Без сборки и зависимостей: `index.html` + `style.css` + `app.js` + `exercises.js`.

## Что умеет

- **Живая тренировка**: таймер, упражнения из библиотеки (85 штук, рус/англ названия,
  фильтр по мышцам и оборудованию), подходы с весом, повторениями и RPE, типы подходов
  (разминка, дроп, отказ), «было в прошлый раз» в каждом ряду, пустое поле = как в прошлый раз.
- **Таймер отдыха** стартует после каждого подхода, звук и вибрация по окончании,
  время отдыха настраивается для каждого упражнения.
- **Рекорды**: максимальный вес и расчётный 1ПМ (формула Эпли), повторения, время, дистанция.
- **Оборудование**: поле «настройки тренажёра» у каждого упражнения (сиденье 4, упор 3…),
  запоминается и подставляется в следующий раз. Клуб (Elixia и другие) в профиле и в тренировке.
- **Самочувствие**: сон, энергия, настроение, крепатура, вес, заметка. Итог тренировки: RPE 1–10,
  ощущения, заметка.
- **Программы**: свои и готовые (Всё тело А/Б, Push/Pull/Legs, Верх/Низ), «повторить последнюю»,
  «сохранить тренировку как программу».
- **Групповые занятия** (BODYPUMP, RPM и т.п. из расписания Elixia) одной кнопкой.
- **История**: календарь-теплокарта по месяцам, карточка тренировки, редактирование, удаление.
- **Прогресс**: тоннаж по неделям, график 1ПМ по упражнению, вес тела, сон.
- **Данные**: бэкап JSON, экспорт CSV, импорт бэкапа и CSV из Strong / Hevy.
- **PWA**: манифест и service worker, работает офлайн, ставится на экран «Домой».

## Хранение и синхронизация

Всё хранится в `localStorage`. Если страница открыта как артефакт claude.ai, данные
дополнительно синхронизируются в его базу (capability `db`, приватное поддерево
`data/users/<id>/main` и коллекция `workouts`) и доступны с любого устройства, а Claude
может читать их для отчётов.

## Запуск локально

```bash
cd gym
python3 -m http.server 8080
# открыть http://localhost:8080
```

Для телефона удобнее выложить папку на любой статический хостинг (GitHub Pages, Netlify).

## Elixia

У Elixia / SATS нет публичного API, поэтому прямой интеграции с их приложением нет.
Занятия из расписания записываются вручную через «Групповое занятие».
